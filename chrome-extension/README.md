# Music Desktop 桌面歌词（Chrome 扩展）

把 Music Desktop 正在播放的歌词，浮动显示在**当前网页的最上层**。
因为歌词是网页自己的一部分，所以浏览器全屏（含 macOS 的全屏空间）时也不会被盖住。

## 安装（一次即可）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择本文件夹（含 `manifest.json` 的目录）。
4. 列表里出现「Music Desktop 桌面歌词」即安装成功。

## 使用

1. 打开 **Music Desktop** 播放歌曲（歌词接口由它提供）。
2. 在任意网页里播放，副屏上的 Chrome 全屏页面底部就会显示歌词：
   当前行 + 翻译 + 下一行。
3. 没有在放歌（或 Music Desktop 没启动）时，歌词会自动隐藏，不留痕迹。

## 快捷键

- `Alt + Shift + L`：在**当前标签页**开关歌词（有的页面只想看内容、不想看歌词时用）。
  按一次关，再按一次开；只影响当前标签页，其它窗口不受影响。

## 说明

- 歌词接口只监听本机地址 `127.0.0.1`（端口 39517/39518/39519），不对局域网开放。
- 想调整字号、位置、颜色，改 `content.js` 里 `host.style` 的 `bottom` 和 `style.textContent` 中的字号与 `color` 即可，
  改完在 `chrome://extensions` 里点扩展卡片上的刷新按钮，再刷新网页。
- Chrome 系统页面（如 `chrome://settings`）不允许注入，属正常现象。
